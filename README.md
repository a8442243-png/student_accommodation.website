# Student Accommodation Website
A responsive web application designed to help students find suitable Paying Guest (PG) accommodation based on location, budget and gender preferences.

## Project Overview
Student Accommodation is a PHP and MySQL based web application developed to make the process of finding student-friendly accommodation easier.

Users can browse available PG properties, apply filters, view complete property details, create an account, log in, and shortlist properties they are interested in.

## Features
- User Registration and Login
- Secure User Sessions
- Browse PG Properties
- Filter properties by:
  - City
  - Maximum Budget
  - Gender
- Property Details Page
- Property Images
- Property Rating
- Property Description
- Amenities Information
- Interested / Enquiry Feature
- Shortlist Properties
- Remove Properties from Shortlist
- Responsive User Interface
- AJAX-based property filtering
- MySQL Database Integration
